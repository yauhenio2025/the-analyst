# Fixture evidence, not historical findings

`synthetic_packet.json` is a wholly invented two-author × two-person packet with two exclusive figures, one unknown year and a coauthored exclusion record. `synthetic_output.json` exercises inherited sources and final residue cells. `synthetic_two_author_index.json` gives both authors the same integer ref_id and one shared P witness; author-qualified events and original source identities keep these joins distinct.

`overlap_packet.schema.json` and `overlap_output.schema.json` are standalone Draft 2020-12 schemas. The builder reuses the cohort's strict row, anchor, artifact, pair-table and plan shapes, extending only overlap ownership and metadata. Run `validate_overlap.validate_packet(packet)` and `validate_overlap.validate_output(packet, output)` after JSON loading. `release=True` rejects all synthetic and mixed packets. Schema success is not a semantic or exporter-provenance pass.

All counting units are canonical citation events. Counts/texts/years/kinds can be derived from the event arrays. Work identity metrics mark incomplete resolved sets explicitly. Full texts for residue-only metadata are not required, but source bytes for every retained interpretive anchor are required.

`../assemble_pilot_fixture.py::assemble(job, export, seed, riley_uid=..., weber_uid=..., source_metadata=...)` is the future mixed fixture assembler. Supply the completed requested Riley→Weber job, its explicit pair export and gap-free receipt, a one-person overlap seed containing the REAL side's canonical count/coverage snapshot and a synthetic second-author pair, and an explicit source metadata mapping. Source metadata per key contains author_uid (null for P), role, year, coauthors, fixture_only=false. Do not manufacture these from a memo. The seed's second author is named `Fixture second author` and uses a `fixture:` UID. The output keeps actual Riley bytes and owning engine, adds only labelled synthetic support scaffolding and remains fixture_only. Pending jobs and gap-bearing exports refuse. Its tests use entirely synthetic stand-ins; no real pilot-derived JSON is bundled.
