Each single-paper condition uses the whole supplied paper, not an excerpt. Corpus inputs retain distinct source keys and full texts. G2 uses Castoriadis Technique/Rationality to test concept comparison without conflating local and social scope. G3 uses Deutschmann’s first religion article and its later interpretation to test attributed reuse. G4 uses Promise and the later interpretation to test whether later caution really revises an earlier claim. Two same-year texts are never ordered by input sequence.

Single-paper genre fit: A4 Harris/Hegel contain inferential counterexamples and conceptual dependency tests; A5 Elling/Zambrana develop tensions; A6 Elling/Chen advance modal claims; C1 Zambrana/Hegel make fine semantic distinctions; C6 AUKUS/Chen apply or criticize theoretical frameworks; S3 Promise/subsea have temporal exposition and local narratives; E12 AUKUS/Promise construct theoretical explanations; A3 Harris/AUKUS rely on comparison. These are design-informed materials, not a held-out generalization test.

Original controls use immutable copies of the source capability’s original problematique, researcher question and all probing questions, rendered by study_two_engines.old_prompt through the first-queue import. Thus old means original analytical questions; this differs from the first-queue lift study’s legacy-JSON extraction/schema rendering. Controls receive the same whole paper and one Sol call. The source engine’s original dimensions are retained even when an enlarged merged method covers supplementary questions.

Source review precedes all scoring. Every completed output gets a substantive source-read memo bound to its SHA256, with checked passages, important successes, errors, retained qualifications, completeness limits and a provisional release judgment. All memos must be committed before the scoring command admits a purchase. Judges see the full sources, one analysis and the requested artifact, with receipts removed, no other rating and no source memo. Scores supplement source review. A6/C1/E12 are assessed primarily by anchors, meaningful inventory rows and source accuracy; a low novelty mark alone is no release veto.

Release requires both requested new conditions completed, code-valid source/anchor/ID delivery and no material source error or unsupported consequential table cell in the review. A corpus release additionally requires complete two-key rows and a correctly scoped relation on the natural pair. A useful but incomplete test can justify a research hold; no score threshold overrides a source defect. Missing comparisons, ratings or capacity to run them are disclosed. Registration is distinct from release.
